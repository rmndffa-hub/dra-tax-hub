Tulis Berita Baru

Isi formulirnya, lihat pratinjaunya, lalu unduh berita.js yang sudah berisi artikel baru + semua artikel lama. Timpa file lamanya, unggah ulang ke Netlify, selesai.

Empat langkah

  1. Isi formulir di bawah — pratinjau di sebelahnya berubah otomatis.
  2. Klik Unduh berita.js. File berisi artikel barumu di urutan paling atas plus seluruh artikel lama.
  3. Di folder situsmu, timpa assets/js/berita.js dengan file yang baru diunduh.
  4. Seret ulang seluruh folder ke app.netlify.com/drop — atau ke situs Netlify yang sudah ada lewat menu Deploys.
